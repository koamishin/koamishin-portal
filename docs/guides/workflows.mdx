# Common workflows

## Start a new local instance

Follow [installation](../getting-started/installation.mdx) to install dependencies, configure a database, run migrations, and create the initial administrator. Then start the application and its supporting processes as described in [local development](../getting-started/local-development.mdx). A fresh migrated instance redirects to `/setup` until a `super_admin` exists.

## Connect an application

Create an organization and application in the admin panel, then inspect its OAuth client and registered callbacks. Choose a client appropriate for the consuming application and validate the complete authorization flow. The [integration guide](core-concepts.mdx) explains the current provisioning, environment, scope, and isolation limits. Use the [metadata guide](user-metadata.mdx) if the application needs extra user values.

## Release an update

Back up the database, uploaded files, and required keys; build the matching application assets; apply and validate migrations; refresh caches; and restart long-running processes. The [deployment guide](ci-cd.mdx) provides the full sequence and operational considerations. Build and deploy the [Astro site](landing.mdx) separately.
