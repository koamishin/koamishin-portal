# Extensibility

Follow the existing Laravel, Vue and Filament conventions when adding functionality. The application discovers Filament resources, pages and widgets in `app/Filament/`. Enabled modules can provide a Filament plugin through the registration in `AppServiceProvider`; inspect the existing Blog module before adding another module. See [contributing](../../CONTRIBUTING.md) for validation and project rules.
