# Directory structure

- `app/`: application models, providers, controllers, jobs, settings and Filament resources.
- `config/`, `routes/`, `bootstrap/`: configuration, routes and application bootstrapping.
- `database/`: migrations, factories and seeders.
- `resources/js/`, `resources/css/`, `resources/views/`: Vue/Inertia, styles and Blade views.
- `Modules/Blog/`: the Blog module.
- `packages/`: local JavaScript and PHP authentication client source.
- `docker/` and `docker-compose.yml`: container configuration requiring review before production.
- `tests/`: Pest tests; `.github/workflows/`: CI and release workflows.
