# Directory structure

Use these paths to find the source you need before making a change:

| Path                                                  | Contents                                                                                 |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `app/`                                                | Models, controllers, providers, jobs, settings, and Filament resources.                  |
| `config/`, `routes/`, `bootstrap/`                    | Configuration, routes, and application bootstrapping.                                    |
| `database/`                                           | Migrations, factories, and seeders.                                                      |
| `resources/js/`, `resources/css/`, `resources/views/` | Vue/Inertia pages, styles, and Blade views.                                              |
| `Modules/Blog/`                                       | The enabled Blog module and its migrations.                                              |
| `packages/`                                           | Local JavaScript and PHP authentication client source.                                   |
| `docs/` and `landing/`                                | Documentation source and the separate Astro site.                                        |
| `docker/` and `docker-compose.yml`                    | Container configuration; review the [deployment guide](ci-cd.mdx) before production use. |
| `tests/` and `.github/workflows/`                     | Pest tests and GitHub Actions workflows.                                                 |
