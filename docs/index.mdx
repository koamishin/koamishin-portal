# Koamishin Portal

Koamishin Portal is a Laravel application with Vue/Inertia user pages, a Filament administration panel, account management, Passport OAuth clients, tenant records and webhook delivery. Start with [installation](getting-started/installation.mdx), then read [configuration](getting-started/configuration.mdx) and [deployment](guides/ci-cd.mdx).

The [architecture](architecture.mdx), [tenancy and OAuth guide](guides/core-concepts.mdx), and [security guide](guides/security.mdx) describe important implementation limits. The [Astro landing guide](guides/landing.mdx) covers its separate build and deployment. The project is licensed under the MIT License; see the root `LICENSE` file.
