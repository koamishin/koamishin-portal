# Koamishin Portal documentation

Koamishin Portal is a Laravel application for managing user accounts and OAuth clients. It includes a Filament administration panel, tenant and application records, account settings, and queued user webhooks. This documentation describes the behavior in this repository and helps you set up and operate your own instance.

## Start with the Portal

1. [Install the Portal](getting-started/installation.mdx) and create the first administrator.
2. [Configure the environment](getting-started/configuration.mdx), including the database, URL, mail, and queue.
3. [Run the development services](getting-started/local-development.mdx); the installation guide also shows how to create an organization and application.
4. Read the [deployment guide](guides/ci-cd.mdx) before exposing an instance to users.

## Build an integration

- Follow the [two-app centralized login and registration walkthrough](getting-started/centralized-auth.mdx) to register one user and connect two Laravel applications.

- [Tenancy and OAuth integration](guides/core-concepts.mdx) explains application records, clients, endpoints, and webhooks.
- [Laravel SDK](guides/laravel-sdk.mdx) explains login, server credentials, sessions, and webhooks.
- [User metadata](guides/user-metadata.mdx) shows how to add, read, and update extra user values.
- [API reference](reference/examples.mdx) lists the main endpoints and how to inspect the routes available in your installation.
- The repository includes [JavaScript](../packages/koamishin-auth-js/README.md) and [PHP](../packages/koamishin-auth-php/README.md) client source. Review their documented compatibility limits before using them.

## Understand the current boundaries

OAuth userinfo, the management API, and user webhooks enforce the application-environment checks described in this guide; other Portal features are not automatically tenant-isolated, and super administrators have global access. Although the Portal publishes discovery metadata, it does not currently issue OpenID Connect ID tokens or handle OIDC nonces. Read [tenancy and OAuth](guides/core-concepts.mdx) and [security](guides/security.mdx) before connecting applications or handling sensitive data.
